# Runefall v0.7.0: Living Gems and Restored Worlds

**Status:** Android graphics-focused prerelease, one game codebase for phone/tablet. APK distribution uses direct standalone downloads, never ZIP-only.

## Graphics and world restoration

- Six new original 256x256 beveled gemstone materials, generated offline from source code tools/make_v07_art.py. Existing glyph fonts/symbol choices are preserved.
- Chromatic impact shockwaves, magical light rays, crystal shard fragments, light pulses reflected onto nearby sockets, threshold star sparks and amplified victory visuals. New rendering is decoupled from game state and save snapshots.
- Twenty original transparent environment overlays: one per world and per restoration stage (0–4). Runes: icy torchlight; Egypt: desert glows; East Asia: blossoms/lanterns; Mixed: arcane spirals and motes. Stage 4 reveals a fully restored portal and magical beams.
- World-specific idle particles, floating facets, slow parallax, gentler gravity spring easing, and optional minor screen shake.
- Phone portrait, tablet portrait and tablet landscape use the same gameplay, worlds, lighting and save data.

## Accessibility and performance

All upgrades honor existing settings: Reduce Motion, Low Effects, Gem Shimmer, Reactive Light, Ambient Motion and Screen Shake. Low Effects lowers particle/debris cost and rendering tick rate; Reduce Motion turns off the new motion effects. Graphics are drawn with 2D canvas calls and prebuilt PNG assets on the project's Godot GL Compatibility renderer; no new internet access or plugins are required.

## Gameplay preservation

The v0.6.2 clear-rate rules remain exactly 75% / 85% / 100% for 1 / 2 / 3 stars. One free deadlock rescue remains. 48 Quest boards and their certified clearing solutions, Arcade Mode, saves/Undo, the four original music tracks plus menu theme, world progress, relics and booster controls are carried forward. This version introduces **no ads, paid boosts, or billing permissions**.
