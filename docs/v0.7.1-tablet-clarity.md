# Runefall v0.7.1: Tablet Clarity Hotfix

The game renders distinct phone/tablet layouts. The tablet UI was soft because the manual drawing path scales multiple custom fonts with a non-integer transform and overlays several offset text labels. Its background and some UI sprites are also bitmap sources.

- Bundle open-license Noto Sans for Latin UI and enable MSDF for Noto, ancient glyph fonts and DejaVu display headings (72px MSDF source size).
- Enable project font oversampling and mipmapped fonts, preserving Godot's native-resolution canvas_items stretch mode.
- Replace triple-rendered rune labels with one glyph pass and a thin outline. Reduce offset shadows for small tablet UI copy.
- Recheck 864x1536 screenshot size supplied by a tablet user, plus 1200x1920 tablet portrait and 1920x1200 tablet landscape.
- Keep all gameplay logic, saved progress, sound, input coordinates and Android package names intact.

Note: existing 720x1440 world background PNGs can still look softer than fully native 2K artwork. This hotfix targets text/typography and glyph clarity; upgrading all backgrounds requires original high-resolution illustration source, not just upscaling the old bitmaps.
