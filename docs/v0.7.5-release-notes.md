# Runefall v0.7.5 — Relics, World Map & Arcane Powers

**Android development prerelease.** Direct standalone signed APKs; no ZIP bundles.
Game title and trademark clearance remain commercial launch issues.

## New gameplay

- **Optional powered gemstones** created by match-four (row/column blast), match-five (wildcard same-type clearing), or T/cross combinations (area explosion). Powers live on surviving existing gems, so Quest still has **no refill** and existing certified level-clearing paths remain valid. Double-tap a glowing power gem to activate it. Powers move with gems during swaps/gravity, and survive Undo, Shuffle and saved games.
- **48-node world maps**, 12 nodes per civilization, connected paths, star ratings, locked levels and relic milestone decorations (3, 6, 9, 12).
- **Eight offline achievements** for matching, victories, perfect clears, combos, first relic, restoring a world, 10 quests, and visiting all four civilizations.

## Relic reward overhaul

- First-time milestone completion reveals a named **RELIC FOUND!** reward scene with a rotating gold ring, stars and sound. Continue and View Relics actions are offered.
- A persistent reward queue survives interruption or app restart and prevents repeat celebrations on replays. The collection shows unseen relic badges, including relics collected on older releases.
- Restored-world counts update alongside the relic. Motion effects respect accessibility preferences.

## UI and visual repairs

- Streamlined menu with a settings gear icon, four world cards as the only world selector, compact Level Map / Progress / Relics actions and one primary Begin/Continue action.
- A cleaner, center-cropped menu backdrop replaces duplicate background drawing and suppresses obsolete controls baked into historical backdrop artwork.
- Responsive phone/tablet layouts, MSDF fonts and save compatibility from v0.7.1 remain.

## Existing systems preserved

- Quest 75%/85%/100% star rules, one free rescue, all 48 certified puzzles, soundtracks, existing relics, world restoration, Arcade, offline saves and the original package IDs.
- **No ads, paid boosters, subscriptions, purchasing SDKs or accounts** until v0.8.0.

## Testing

- Godot 4.7.2 import and scripted gameplay/reward/special-gem tests.
- Real Godot screenshots for Home, World Map, collection, achievements and the relic reveal at phone and tablet sizes.
- Both APK variants installed on Android 16 emulators and re-signed with the same persistent GammaPi testing certificate as v0.7.1.
- Signature schemes v1/v2/v3 and SHA-256 integrity after upload.
- Physical Android device installation, performance, and accessibility still need user confirmation.
